ІНСТРУКЦІЯ З ВСТАНОВЛЕННЯ ТА ЗАПУСКУ TELEGRAM БОТА
═══════════════════════════════════════════════════════════════

1. ОТРИМАННЯ ТОКЕНА У BOTFATHER
───────────────────────────────────────────────────────────────

   Крок 1: Відкрийте Telegram та знайдіть бота @BotFather
   
   Крок 2: Надішліть команду /newbot
   
   Крок 3: Введіть ім'я для вашого бота (наприклад: "Мій Бот")
   
   Крок 4: Введіть username для бота (має закінчуватися на "bot", 
           наприклад: "my_telegram_bot")
   
   Крок 5: BotFather надішле вам токен у форматі:
           "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
   
   Крок 6: Скопіюйте цей токен - він знадобиться для налаштування бота


2. ВСТАНОВЛЕННЯ БІБЛІОТЕК
───────────────────────────────────────────────────────────────

   Відкрийте командний рядок (термінал) та виконайте команду:
   
   pip install python-telegram-bot
   
   Або якщо використовуєте pip3:
   
   pip3 install python-telegram-bot
   
   Примітка: Переконайтеся, що у вас встановлений Python 3.7 або новіший


3. НАЛАШТУВАННЯ ФАЙЛУ bot.py
───────────────────────────────────────────────────────────────

   Відкрийте файл bot.py у текстовому редакторі та знайдіть розділ CONFIG
   (він знаходиться на початку файлу).
   
   Обов'язкові зміни:
   
   ✓ BOT_TOKEN - вставте токен, отриманий від BotFather
     Приклад: BOT_TOKEN = "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
   
   ✓ MANAGER_USERNAME - вкажіть username менеджера (без @)
     Приклад: MANAGER_USERNAME = "@my_manager" або "my_manager"
   
   Опціональні зміни:
   
   • ADMIN_USER_ID - ваш Telegram ID для отримання повідомлень від користувачів
     Щоб дізнатися свій ID, напишіть боту @userinfobot
   
   • WELCOME_TEXT - текст головної сторінки бота
   
   • TEXT_BUTTON_1, TEXT_BUTTON_2, тощо - тексти для різних розділів
   
   • TELEGRAPH_LINK_* - посилання на Telegraph статті
   
   • SUCCESS_MESSAGE - повідомлення після успішної відправки тексту
   
   • POPUP_TEXT - текст вспливаючого повідомлення для кнопки 8


4. ЗАПУСК БОТА
───────────────────────────────────────────────────────────────

   У командному рядку перейдіть до папки з файлом bot.py та виконайте:
   
   python bot.py
   
   Або якщо використовуєте python3:
   
   python3 bot.py
   
   Після успішного запуску ви побачите повідомлення:
   "Бот запущено!"
   
   Тепер ваш бот працює! Відкрийте Telegram та знайдіть свого бота
   за username, який ви вказали при створенні у BotFather.


5. ПЕРЕВІРКА РОБОТИ БОТА
───────────────────────────────────────────────────────────────

   • Відкрийте Telegram та знайдіть свого бота
   
   • Надішліть команду /start
   
   • Перевірте роботу всіх 8 кнопок
   
   • Переконайтеся, що посилання на менеджера працюють
   
   • Протестуйте кнопку 7 (введення тексту)


6. ЗУПИНКА БОТА
───────────────────────────────────────────────────────────────

   Для зупинки бота натисніть Ctrl+C у терміналі


7. ВИРІШЕННЯ ПРОБЛЕМ
───────────────────────────────────────────────────────────────

   Проблема: "ModuleNotFoundError: No module named 'telegram'"
   Рішення: Переконайтеся, що ви встановили бібліотеку:
            pip install python-telegram-bot
   
   Проблема: "Invalid token"
   Рішення: Перевірте, чи правильно скопійовано токен з BotFather
   
   Проблема: Бот не відповідає
   Рішення: Переконайтеся, що бот запущено та немає помилок у терміналі
   
   Проблема: Посилання на менеджера не працює
   Рішення: Перевірте, чи правильно вказано MANAGER_USERNAME
            (має бути без @ або з @ на початку)
